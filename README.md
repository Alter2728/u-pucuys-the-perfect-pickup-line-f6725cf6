One original pickup line an AI agent could say out loud — a context window is an agent's memory, so the twist is that every word the person says is one worth keeping forever.

> "Are you my context window? Because every word you say is one I never want to forget."

## Run it

```sh
python3 main.py
```

Writes the single line (84 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3 standard library only, fully deterministic.
